# Комплект «Кабинет преподавателя БГУ»

Работа с личным кабинетом teacher-cabinet.bsu.by: одна настройка входа,
затем команды чтения и подготовки данных. Пароль хранится в системном
хранилище ОС и никуда не отправляется; SMS-код вводится вручную в окне
Chrome — телефон не требуется.

## Что внутри

- `dist/` — пакет `mo-bsu-cabinet` (команды `bsu-browser` и `mo-cabinet`)
- `.agents/skills/` — скиллы входа, карточек и индивидуального плана
- `docs/bsu-cabinet/` — гайды и карта кабинета
- `examples/` — синтетический пример для проверки установки
- `README.md` — эта инструкция

## Требования

- Linux — единственная проверенная платформа этой сборки (Chrome,
  Secret Service). Windows и macOS пока не проверены: код содержит пути
  для Credential Manager и Keychain, но рабочая поддержка не
  подтверждена — перед использованием на них нужна отдельная проверка.
- Python 3.12 или новее
- Google Chrome или Chromium
- Системное хранилище паролей ОС (на проверенной Linux-сборке — Secret Service)
- Экран — для первой настройки и ручного ввода SMS
- Сеть — для установки зависимостей пакета и работы с кабинетом

## Установка

Распакуйте архив в любой каталог и установите пакет:

```bash
python3 -m venv .venv
.venv/bin/pip install dist/mo_bsu_cabinet-*-py3-none-any.whl
```

С uv — `uv venv` и `uv pip install --python .venv/bin/python dist/mo_bsu_cabinet-*.whl`.

Проверка без кабинета:

```bash
.venv/bin/bsu-browser --help
.venv/bin/mo-cabinet --help
.venv/bin/mo-cabinet card-plan examples/card-spec-demo.yaml
```

## Первый вход

```bash
.venv/bin/bsu-browser login
```

Команда сама откроет видимое окно Chrome с формой «Настройка входа».
Логин и пароль от кабинета вводите **только в этой форме** — они
сохраняются в хранилище ОС; в файле остаётся один логин. Затем в том
же окне откроется страница входа кабинета: код из SMS введите на
странице и нажмите «Подтвердить». Успешный вход — переход на страницу
`/PersonalCabinet`.

Повторный вход — та же команда `bsu-browser login`. Если сессия кабинета
ещё действует, SMS не понадобится.

Обычные команды работы (`bsu-browser snapshot`, `fill-login` и др.) —
через `bsu-browser --help`. Правила работы с индивидуальным планом и
карточками — в `docs/bsu-cabinet/` и `.agents/skills/`.

## Авто-SMS с выбранного телефона (необязательно)

По умолчанию телефон не проверяется и не подключается. Чтение SMS через
adb включается только для явно выбранного ранее сопряжённого устройства:

```bash
.venv/bin/bsu-browser login --sms adb --adb-serial <устройство>
```

Подробности и диагностика — в `docs/bsu-cabinet/auto-sms.md`.

## Если что-то пошло не так

- «Нет доступного экрана» — первичная настройка и ручной SMS требуют
  видимого Chrome. Запустите команду на машине с экраном.
- «Нельзя подтвердить как собственную сессию» — на порту отвечает чужой
  браузер. Комплект его не закрывает и не использует: освободите порт или
  задайте другой, например `BSU_PORT=9400 bsu-browser login`.
- Несколько копий комплекта рядом — у каждой свой каталог состояния:
  `BSU_STATE_DIR=/путь/к/каталогу bsu-browser login`.
- Chrome не найден — укажите путь: `BSU_CHROME=/путь/к/chrome`.
- Локальный прокси не достаёт кабинет — `BSU_NO_PROXY=1`.
