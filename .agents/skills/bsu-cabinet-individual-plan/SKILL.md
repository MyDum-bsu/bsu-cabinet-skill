# Индивидуальный план (PersonalPlan)

1. **Загрузи правила:** [гайд-схема индивидуального плана](../../../docs/bsu-cabinet/individual-plan-guide.md) определяет перенос полей, практики/курсовые/ГЭК и четыре сверки. Технические поля и статусы — в [карте кабинета](../../../docs/bsu-cabinet/cabinet-map.md). Вход: [bsu-cabinet-login](../bsu-cabinet-login/SKILL.md).
2. **Рассчитай план из Excel:** определи преподавателя, год, три блока и поля по заголовкам. Потоки, группы и подгруппы переноси только в одноимённые поля. Для полного ШТ с назначением только подгрупп ставь 0 групп и указанное число подгрупп. Пустота в неполном источнике не означает 0. Гайд задаёт правила для всех полей и трёх блоков.
3. **Сверь с кабинетом:** открой `https://teacher-cabinet.bsu.by/Teacher/PersonalPlan`, прочитай строки и справочник. Сравни числа по каждому полю, затем четыре итога. Покажи «ячейка ШТ → поле кабинета → было → станет» и «ШТ / сейчас / после». Однозначное подготовь без вопросов; конфликты и недостающие источники собери одним списком.
4. **Запись после согласия:** используй существующую строку при совпадении ключа; «Добавить» сразу создаёт строку. Перед отправкой сверь фактические поля формы или запроса с рассчитанными из ШТ, особенно пару `CountGroups` / `CountGroupsSub`. После записи перезагрузи страницу и проверь оба поля. При расхождении остановись. В отчёте отличай «предпросмотр, не записано» от «сохранено и перечитано». Отправка на проверку требует отдельного согласия.
