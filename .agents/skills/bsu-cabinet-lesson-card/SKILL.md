# Карточки занятий (CardOne)

1. **Загрузи правила:** [гайд карточек](../../../docs/bsu-cabinet/lesson-card-guide.md) определяет роли, календарь, источники каждого поля и условия подтверждения. Для технических полей используй [карту кабинета](../../../docs/bsu-cabinet/cabinet-map.md). Вход: [bsu-cabinet-login](../bsu-cabinet-login/SKILL.md).
2. **Сопоставь строку плана:** открой `https://teacher-cabinet.bsu.by/Teacher/CardOne`, выбери учебный год, семестр и точную строку ИП в дереве, не «Весь год». Если строки нет, переходи к [ИП](../bsu-cabinet-individual-plan/SKILL.md). Read-only закончен, когда известны нужный ключ, вид и сохранённые строки.
3. **Собери предпросмотр:** возьми виды работ и часы из ИП, личные даты из последней действующей редакции расписания, темы из программы или тематического плана. Для ранних дат не требуй архив редакций: примени известные переносы, а остальные даты рассчитай по действующему расписанию. Отметку о проведении ставь по отдельному подтверждению. `uv run mo-cabinet card-plan <yaml>` только разворачивает уже заданные даты. Покажи поля и источники; точные дубли исключи, препятствия собери одним списком.
4. **Покажи форму без сохранения.** Для одной записи вводи только согласованный номер одной группы. При добавлении `2б` становится `2`; подгруппа в примечании видна в предпросмотре. Кнопка «Сохранить» сразу записывает, а `CardOneSave` заменяет всю таблицу для ключа и вида. До согласия не вызывай её, не редактируй и не удаляй прежние строки.
5. **После подтверждения** запиши только согласованное. Перечитай поля после обновления и проверь, что прежние строки сохранились. При первом отличии остановись и покажи расхождение.
