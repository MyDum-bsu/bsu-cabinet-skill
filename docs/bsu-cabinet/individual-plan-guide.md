# Индивидуальный план преподавателя: из нагрузки в кабинет БГУ

Основание — памятка ФПМИ «Личный кабинет преподавателя ФПМИ», стр. 1–8, и [карта кабинета](cabinet-map.md). План фиксирует **запланированную** нагрузку. Записи о фактическом выполнении и карточки занятий оформляются отдельно.

> **ШТ → осенний блок + весенний блок + годовые работы → сверка трёх итогов и общего «Запланировано» → сохранение черновика → повторная сверка.** Отправка на проверку — отдельное действие.

## 1. Подготовить данные и снять текущее состояние

1. Прочитай файл нагрузки. Выбери преподавателя и учебный год по файлу и открытому кабинету. Для одного однозначного набора ничего не переспрашивай; если в книге несколько преподавателей, редакций или лет и кабинет не разрешает выбор, попроси указать нужный набор один раз. Найди три блока по **текстам заголовков**, а не по буквам столбцов и не по цифрам из презентации. Прочитай строки данных, формулы и сохранённые значения итогов.
2. В кабинете открой «Преподаватель → Индивидуальный план» (`/Teacher/PersonalPlan`). Проверь учебный год, статус редактирования плана и уже заполненные строки всех трёх разделов. Если план закрыт для редактирования, выдай таблицу изменений без попытки сменить статус.
3. Сопоставь справочник кабинета по названиям из файла: **факультет → специальность и дисциплина**, затем курс, форма обучения и семестр. Сокращение раскрывай по однозначному соответствию в справочнике. Не подставляй коды из другого преподавателя/факультета. Если совпадений несколько, не выбирай первое.
4. Для каждой исходной строки зафиксируй адрес «лист, строка, заголовок», её семестровые и годовые значения. Один Excel-ряд может дать две семестровые строки и несколько годовых вкладов; строка «Итого» только для проверки. Часы складывай точно, без повторного умножения на ставку, группы, подгруппы или число студентов. Пустая ячейка часов — отсутствие работы только при проверенном заголовке и формате файла; пустой результат формулы или обязательный реквизит — не ноль.

Разбирай XLSX по паре **«раздел → заголовок поля»**: одно и то же название в осеннем и весеннем блоках означает разные значения. Если используешь автоматический разбор, принимай результат только когда он сохраняет это соответствие и все контрольные суммы сходятся с книгой. Ошибка разбора, ненайденный заголовок и формула без сохранённого результата — не нули; блокируй запись зависимых полей.

## 2. Разнести три блока (памятка, стр. 1–3)

| Что в ШТ | Куда в ИП | Что проверять |
|---|---|---|
| Осенний блок | «Учебная работа (осенний сем.)» | Каждая ненулевая строка по своим полям и сумму «Всего за семестр запланировано». |
| Весенний блок | «Учебная работа (весенний сем.)» | Только весенние часы той же дисциплины. Сумма «Всего за семестр запланировано» равна весеннему блоку ШТ. |
| Руководство, рецензирование, итоговая аттестация, иные виды | «Учебная работа (в течение года)» | Сумма часов по каждому виду за год и «Всего за учебный год запланировано» для **этого раздела**, без семестровых часов. |
| «Всего за год» | «Учебная работа (итого)» → «Запланировано» | Контроль, не дополнительная строка для ввода. Суммы осени, весны и годовых работ вместе равны итогу ШТ. |

### Семестровая строка: что переносить

Создавай строку только для семестра с назначенной работой: например, только передэкзаменационная консультация тоже основание для строки. Чисто годовая работа не требует пустой строки в семестре.

| Поля кабинета | Перенос из строки ШТ |
|---|---|
| Факультет, специальность, дисциплина, курс, форма обучения | Значения строки. Форму выбирай по подписи в кабинете. Не считай любую неочную форму заочной. |
| Потоки, группы, подгруппы | Одноимённые колонки → `CountLine`, `CountGroups`, `CountGroupsSub` соответственно. Сверяй как набор по правилу ниже. |
| Студенты по лекциям, практике, лабораторным; иностранные | Одноимённые колонки. Количество студентов в основной колонке уже включает иностранных, второй раз их не прибавлять. Это численность, не часы. |
| Лекции, практические/семинарские, лабораторные, УСР | Каждый вид отдельно, аудиторные и ДОТ отдельно. Перенос 1:1 по официальному файлу, даже если в повседневной речи вид называется иначе. |
| Консультации | «Текущие» → текущие; «групповые перед экзаменом» → групповые. Коллоквиум/индивидуальные — только из соответствующей подтверждённой нагрузки. |
| Проверка работ | Если форма даёт одно «Проверка работ», сложи контрольные, рефераты и другие письменные из **этого** семестра. Сохрани разложение в отчёте; не добавляй туда руководство курсовыми. |
| Экзамен/дифференцированный зачёт; обычный зачёт | Первая колонка — поле экзамена/дифференцированного зачёта, обычный зачёт отдельно. Не переносить дифференцированный зачёт в обычный только по слову «зачёт». |
| Экзаменационный просмотр | Сопоставь с отдельным одноимённым полем, если его даёт версия формы. В сохранённом JS у формы нет отдельного поля. Если значение ненулевое и поля нет, пометь строку и разницу как заблокированные; не добавляй часы к экзамену ради совпадения суммы. |
| Фактически выполнено, примечание | «Фактически выполнено» не заполняй из ШТ. Сохраняй существующее примечание; новое — только если известно, что в нём требуется. |

### Потоки, группы и подгруппы

Сначала рассчитай **все три целевых счётчика** из одноимённых колонок одной строки ШТ. Это независимые числа: не вычисляй группы из подгрупп, подгруппы из групп или любой из счётчиков из расписания. Состояние кабинета не участвует в расчёте.

| Значение исходной колонки | Что ставить в одноимённое поле |
|---|---|
| Целое неотрицательное число, в том числе 0 | Это число. Если «Группы» и «Подгруппы» обе заданы, ставь обе, даже если равны. |
| Ячейка действительно пуста в полной актуальной ШТ, где пропуск означает, что этот вид численности отдельно не задан | 0. Например, «Группы» пусто, «Подгруппы» = 3 → `CountGroups = 0`, `CountGroupsSub = 3`. Если заполнены только «Группы», ноль ставится в «Подгруппы». |
| Пропуск в частичном файле, нет заголовка или формула не вычислена | Значение неизвестно. Не создавай ноль и не заполняй из другого счётчика. Покажи блокировку. |

Применяй таблицу одинаково для создания и редактирования. Затем сравни целевые значения с кабинетом и обнови только отличающиеся поля. Например, если там `(3, 0)`, а цель по ШТ `(0, 3)`, одна правка строки должна установить оба значения. Если другой утверждённый источник противоречит ШТ, не выбирай число наугад: покажи конфликт.

### Годовой блок и пограничные случаи (памятка, стр. 4–7)

Для каждой годовой категории сложи её часы по строкам. Сохрани детализацию «строка ШТ → сумма → категория» в предпросмотре, чтобы преподаватель проверил сумму по виду. В кабинете редактируй существующую строку этого вида, не создавай семестровый аналог. У известной формы годовой записи надёжно читается обратно плановое значение `Value`; не обещай сохранение дополнительных метаполей без проверки.

| Работа | Куда разнести |
|---|---|
| **Учебная / производственная практика** | Руководство — соответствующая годовая строка. Дифференцированный зачёт за практику — поле экзамена/дифференцированного зачёта семестра, в котором стоит в ШТ (в примере памятки — весна). Не переносить руководство вместе с зачётом одной суммой. |
| **Курсовые проекты и работы, включая приём защиты** | Годовое «Руководство курсовыми работами, проектами». Если руководство и защита в двух исходных строках, их часы складываются здесь, а не как контрольная работа или экзамен. |
| **ГЭК: госэкзамен** | Групповая консультация перед экзаменом — в соответствующем семестре (в примере — весна); сам госэкзамен — годовая «Итоговая аттестация». |
| **ГЭК: защита дипломных работ** | Годовая «Итоговая аттестация». Руководство дипломом и рецензирование — отдельные годовые категории, если указаны в нагрузке. |
| **Другие годовые работы** | Руководство дипломными работами, магистрантами/аспирантами, рецензирование квалификационных работ и иные виды — в одноимённые строки. Не складывать разные виды в «Иные» ради совпадения итога. |
| **Методработа, НИР, идеологическая и воспитательная работа** | Из плана работы кафедры, а не из ШТ. «Советы, комиссии» также не выводи из учебной нагрузки без отдельного источника. Без плана кафедры оставь эти разделы как есть, отмечая, что учебная часть готова отдельно. |

## 3. Сверить черновик и запросить одно подтверждение

1. Сопоставь текущие строки с ожидаемыми по ключу «год, семестр, факультет, специальность, дисциплина, курс, форма»; если двух строк этим ключом не различить, проверь реквизиты и не схлопывай их сам. Для годового плана ключ — год и вид работы. Отметь каждую строку как **без изменений / добавить / изменить / конфликт**. Существующую строку вне файла не удаляй и не обнуляй.
2. **Сверь числа по каждому полю.** Сначала прочитай значения ШТ по заголовкам; затем сопоставь их с нужными полями кабинета. Отдельно проверь потоки, группы и подгруппы, студентов по каждому виду занятий и иностранных студентов, часы по каждому виду и годовые категории. Численность — целое число; для часов используй точные дроби (`Fraction`) и сравнивай по значению: `18,6` = `18.60`, но пусто не равно нулю без правила для этого поля. Если фактическая точность формы не позволяет сохранить исходное число, покажи расхождение до записи. Результат `row_to_plan_fields()` не заменяет сверку с исходным Excel.
3. **Сверь суммы отдельно.** Пересчитай часы из строк ШТ и сравни с исходными итогами. Покажи четыре строки «ШТ / сейчас / после»: осень, весна, работы за год, учебная работа (итого). Совпадение итогов не отменяет расхождения по полям. Для частичной нагрузки отделяй согласованный объём от остального плана; не выдавай контроль части за совпадение всего плана.
4. Покажи преподавателю только разницы «раздел и ячейка ШТ → поле → было → станет» и список блокировок: что известно, чего не хватает, какое действие нельзя выполнить. При однозначном источнике не задавай вопросы о переносе отдельных полей. Запись требует подтверждения показанного объёма.

## 4. Внести только одобренное, перечитать, остановиться

- Для новой семестровой строки выбери нужный семестр, открой «Добавить пункт», выбери факультет, специальность, дисциплину и нажми «Добавить» **после** подтверждения. Этот шаг уже создаёт строку на сервере; это не предпросмотр. Открой редактирование созданной строки и перенеси утверждённые значения. Существующую строку редактируй на месте. Для годовых работ открой редактирование нужного вида в разделе «В течение года».
- Непосредственно перед сохранением сверь, что исходное состояние не изменилось после согласования. **Сверь отдельно, что фактические поля формы или параметры запроса совпадают с расчётом из ШТ.** Для подгрупп проверь одновременно `CountGroups` и `CountGroupsSub`; правильный дифф не доказывает, что в форму внесли правильную пару. При подмене любого поля остановись до отправки.
- После записи обнови страницу и сверь сохранённые поля, не только значения до обновления или ответ `OK`. Если добавление удалось, а сохранение полей нет, остановись с ключом оставшейся строки; не создавай дубль и не удаляй её автоматически.
- Для численности перечитай весь набор «потоки, группы, подгруппы», даже если менялась только часть. Повтори сверку всех сохранённых чисел и четырёх итогов, выдай «ожидалось → сохранено». При первом несоответствии остановись.
- В отчёте различай «предпросмотр, не записано» и «сохранено и перечитано». В режиме предпросмотра таблица кабинета по-прежнему показывает старые значения, а расчёт отображает новые. Оставь план черновиком. Отправка на проверку (`PersonalPlanChangeStatus`) требует отдельного явного согласия.

## Контрольный пример из памятки

На стр. 2–3 показаны осень **263,2 ч**, весна **268,9 ч** и «Всего за год» **771,1 ч**. Годовые часы **239 ч** отдельно набираются из показанных годовых категорий (58,5 + 73,5 + 78 + 12 + 17); **263,2 + 268,9 + 239 = 771,1**. Это проверка схемы, не значения для нового преподавателя.
